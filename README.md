# РОЙ

2D sandbox / survival / strategy, где вы управляете **не муравьём, а живой колонией**. Рисуете линию — колония сама прокладывает путь: через пропасть строит **живой мост** из тел, по гладкой стене — живую лестницу, сквозь грунт роет тоннель. Колония сама ищет еду, тащит тяжёлое командой, копает комнаты, укрепляет своды, спасает личинок от воды и учится на своих дорогах.

* TypeScript + WebGL2, без движка и зависимостей; работает в браузере, на ПК и телефоне.
* Иерархический роевой ИИ: агенты → команды → отряды → потоки → секции гнезда → колония. Десятки тысяч муравьёв в кадре.
* Разрушаемый процедурный мир (seed): луг, сад с сакурами, дом, улица, подземелье; вода, обвалы, погода, день и ночь, экосистема.
* Графика «Обычная» и «Максимальная» ✦: свечение, лучи солнца, отражения, светлячки, метель лепестков.

```
npm install && npm run dev
```

Режим «Испытание: Пропасть» → инструмент «Маршрут» → проведите линию через пропасть.
